# 신당 배경 픽셀 아트 기획

## 화면의 역할

이 배경은 상담소의 분위기와 공간감을 담당하는 고정된 한 장의 픽셀 아트다. 글자, 버튼, 캐릭터, 클릭 가능한 도구는 배경에 구워 넣지 않는다.

## 화면 기준

- 화면비: 16:9.
- 기준 해상도: 1280×720.
- 작업용 픽셀 해상도: 320×180 또는 640×360 후 정수 배율 확대.
- 시점: 정면보다 약간 위에서 내려다보는 고정 실내 시점.
- 분위기: 생활감 있는 낡은 한국 무당집. 따뜻한 제단빛과 서늘한 창호문 빛이 공존.

## 배경에 그릴 요소

| 위치 | 배경 요소 | 목적 |
| --- | --- | --- |
| 천장 | 나무 들보, 종을 걸 고리, 낡은 끈 | 종 UI가 매달릴 자리 확보 |
| 왼쪽 벽 | 목재 벽, 칠판을 걸 수 있는 빈 틀 | 상담 칠판 UI 배치 공간 |
| 중앙 | 낮은 제단과 손님이 설 빈 자리 | 귀신 캐릭터가 가려지지 않는 무대 |
| 오른쪽 벽 | 병풍, 무신도, 장식 부적, 나무 장 | 한국 무당집 분위기 형성 |
| 뒤쪽 | 창호문, 작은 창, 은은한 달빛 | 밤의 깊이와 색 대비 |
| 하단 | 상담 탁자와 나무 바닥 | 장부·부적·물건 UI를 놓는 전경 |

## 배경에 넣지 않을 요소

- 귀신, 주인공, 상담 대상 인물.
- 칠판의 글씨, 예시 답변, 자연어 입력란.
- 종 본체와 흔들림 효과.
- 장부, 부적, 의뢰 물건, 버튼.
- 날짜, 보유금, 타이머, 업적, 결과 수치.

## 색과 조명

- 기본색: 오래된 나무의 갈색, 종이의 누런색, 먹색.
- 따뜻한 광원: 제단 주변의 주황색, 붉은 촛불.
- 차가운 광원: 창호문과 창에서 들어오는 푸른 밤빛.
- 공포 연출을 위해 배경 전체 명도는 과도하게 밝지 않게 유지한다. 붉은 화면 효과와 검은 침식 효과가 분명히 보이도록 중간 톤을 중심으로 사용한다.

## 안전 영역

- 좌측 상단: 상담 칠판 UI.
- 중앙 우측: 귀신 초상 또는 전신 캐릭터.
- 상단 우측: 날짜와 보유금.
- 하단 전경: 종, 장부, 부적, 의뢰 물건 슬롯.
- 중앙 화면은 텍스트가 겹치지 않도록 복잡한 장식을 피한다.
