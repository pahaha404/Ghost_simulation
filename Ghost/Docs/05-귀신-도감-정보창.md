# 귀신 도감과 정보창

## 목적

귀신을 클릭했을 때 상담에서 얻은 정보를 확인하는 창이다. 단순한 캐릭터 소개가 아니라, 플레이어가 귀신의 규칙과 관계 변화를 추론하는 도구여야 한다.

## 여는 방법과 제한

- 화면 우측의 귀신 초상 또는 전신 캐릭터를 클릭해 연다.
- 상담 중 일반 질문 단계에서는 열 수 있다.
- 핵심 10초 답변 중에는 열 수 없다.
- 침묵 금기 이벤트 중에는 열 수 없고, 클릭 시도 자체가 금기 위반이 될 수 있다.

## 정보창 항목

```text
[귀신 이름 / 별명]
현재 상태: 중립 / 경계 / 협조 / 위험
첫 방문: n일 차
관계 기록: 최근 상담에서 생긴 변화
알려진 고민: 플레이어가 질문으로 알아낸 사실
받은 물건: 귀신에게서 획득한 보상
금기: ??? 또는 해금된 행동 규칙
```

## 정보 공개 규칙

- 첫 방문 직후에는 이름, 겉으로 드러난 고민, 기본 상태만 보여 준다.
- 질문을 할수록 알려진 고민 문장이 추가된다.
- 특별 해결 또는 특정 재방문을 마치면 숨겨진 사연이 열린다.
- 금기는 기본적으로 `???`로 보인다.
- 금기를 알아낸 뒤에는 짧고 행동 가능한 문장으로 표시한다.

예시:

```text
금기: “막차가 온다고 말하지 말 것.”
금기: “종을 울리지 말 것.”
금기: “이름을 세 번 부르지 말 것.”
```

## 시각 방향

정보창은 일반 책보다 무당의 `영안 부적첩` 또는 낡은 접이식 도감처럼 보이게 한다. 반투명 종이, 붉은 도장, 먹 번짐을 사용하되 본문 글자는 읽기 쉽게 유지한다.
