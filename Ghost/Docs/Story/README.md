## 작성 규칙

- 큰 이야기 변경은 `00-게임-스토리.md`에 먼저 반영한다.
- 게임에 직접 표시되는 대사는 별도 문서로 만들고, Unity에서 읽는 텍스트 에셋 경로를 함께 적는다.
- 대사 수정 뒤에는 해당 Unity 텍스트 에셋도 같은 내용으로 갱신한다.
- 시스템 조건·보상·UI 동작은 `Docs/01~07`의 기획 문서에서 관리한다.
