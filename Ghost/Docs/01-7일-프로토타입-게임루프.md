# 7일 프로토타입 게임 루프

## 하루의 흐름

```text
아침 영업 준비
→ 오늘의 귀신 방문
→ 질문 선택 상담
→ 핵심 10초 답변
→ 상담 결과와 사례비 정산
→ 밤 장부 정리
→ 다음 날 또는 7일 결산
```

하루에는 상담 한 건만 진행한다. 상담을 깊게 보고, 귀신의 표정·말투·금기를 기억하는 데 집중하는 구조다.

## 손님 방문 규칙

- 1일 차는 튜토리얼 겸 안내역인 `딱지 할아버지`가 반드시 방문한다.
- 2~5일 차에는 아직 만나지 않은 귀신 중 한 명이 무작위로 방문한다.
- 6~7일 차에는 이미 만난 귀신이 재방문한다. 같은 귀신이 바로 연속 방문하지 않도록 한다.
- 플레이어에게는 무작위 방문처럼 보이지만, 7일 안에 5명의 귀신을 모두 만나도록 내부적으로 보정한다.

## 상담 결과

| 결과 | 의미 | 수입 | 관계 |
| --- | --- | --- | --- |
| 미해결 | 시간 초과, 문맥 이탈, 공격적 태도 | 기본 사례비 50% | 하락 |
| 부분 해결 | 회피하거나 정보를 충분히 얻지 못함 | 기본 사례비 + 소량 보너스 | 유지 |
| 해결 | 적절한 공감 또는 조언 | 기본 사례비 + 보너스 | 상승 |
| 특별 해결 | 귀신 성향에 맞는 답과 충분한 조사 | 기본 사례비 + 최대 보너스 + 물건 환전 | 크게 상승 |

## 수입과 점수

- 귀신마다 기본 사례비와 성과 보너스가 있다.
- 특별 해결 때 받는 물건은 현재 버전에서는 즉시 현금 가치로 환전한다.
- 최종 점수는 7일간 보유한 현금이다.
- 부가 지표는 만난 귀신 수, 특별 해결 건수, 업적 수, 환전 물건 수다.
