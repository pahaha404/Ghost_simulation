## 현재 씬과 UI 구조

### 배경

- `SampleScene`의 `Shrine Background` SpriteRenderer가 신당 배경을 표시한다.
- 배경의 GUID는 유지해야 한다. 픽셀 아트 설정은 Point 필터(`filterMode: 0`)다.
- 배경에 보이는 책·휴대폰·촛불 등은 현재 고정 장식이다. 아직 클릭 가능한 UI가 아니다.

### 편집 가능한 UI

`SampleScene` Hierarchy에 아래 오브젝트가 있다.

```text
Counselor UI
└─ Root
   ├─ Top Bar
   ├─ Content Panel
   │  ├─ Name
   │  ├─ Title
   │  └─ Dialogue
   ├─ Portrait Root (투명, 흔들림 전용)
│  ├─ Portrait Image - Edit Size Here
│  └─ Face (다른 귀신 이미지가 없을 때만 쓰는 숨김 대체 텍스트)
   ├─ Timer
   ├─ Actions - Runtime Buttons
   └─ UI Templates - Edit Style Here
      ├─ Action Button Template
      └─ Answer Input Template
```

프롤로그와 본편은 별도 씬으로 분리한다.

```text
Prologue UI - Opening Story (Screen Space - Camera)
├─ Black Background
│  └─ Prologue Content - Move Me
│     ├─ Story Text
│     └─ Continue Button
├─ Skip Button
Game Camera
Prologue Camera
```

- `Top Bar`, `Content Panel`, `Portrait Root`, `Actions - Runtime Buttons`는 Inspector에서 직접 위치·크기·색을 수정한다.
- 실행 중 실제 버튼은 `Actions - Runtime Buttons` 아래에 생성된다.
- 모든 실행 버튼의 기본 모양은 `Action Button Template`을 수정해 바꾼다.
- 자연어 답변 칸의 기본 모양은 `Answer Input Template`에서 바꾼다.
- `GameScene > Counselor UI` Canvas는 `Screen Space - Camera`이며 Render Camera에 `Game Camera`가 연결돼 있다. UI 위치는 화면 기준이고, Scene 창에서는 게임 카메라 프레임 안에서 확인·수정한다.
- `Prologue UI - Opening Story`는 `Prologue Camera`에 연결된 캔버스다. 별도 밤 신당 배경과 오른쪽 제단의 촛불 하나를 표시한다. `Prologue Content - Move Me`를 선택해 글과 버튼을 Scene에서 함께 옮길 수 있다. 자식 `Story Text`와 `Continue Button`은 따로 조정할 수도 있다.
- `다음 >`을 누르면 빈 줄로 구분한 문단이 AI 답변처럼 한 글자씩 나타난다. 출력 중 한 번 누르면 그 문단을 즉시 완성하고, 완성 뒤에 누르면 다음 문단으로 진행한다. 마지막 `시작하기`는 짧은 검은 화면 뒤 약 1.15초 동안 게임 화면을 서서히 밝히며 `Prologue Camera`를 끈다.
- `Skip Button`은 오른쪽 위의 `SKIP` 버튼이다. 어느 문단에서든 즉시 같은 밝아지는 전환을 거쳐 게임 화면으로 들어간다.
- `GameScene`에는 `Counselor UI`와 `Game Camera`만 남아 있으므로, 프롤로그가 UI 수정을 가리지 않는다. `PrologueScene`에는 프롤로그 UI와 `Prologue Camera`만 남는다.
- 모든 귀신은 `Portrait Root > Portrait Image - Edit Size Here`라는 이미지 슬롯 하나를 공유한다. Root는 투명하고 흔들림·위치 효과만 담당한다.
- 모든 귀신은 `Assets/Art/ghost/`의 자기 이름 폴더에 있는 `default.png`를 사용한다. 거울각시 연화만 질문을 고를 때마다 `default → resentful → thinking → happy`로 표정이 바뀌고, 답변 제한시간 5초에는 `scary`가 표시된다.

### UI 위치 보존 규칙

`GhostGameController`는 `Portrait Panel`의 씬 배치 위치를 `portraitHomePosition`으로 저장한다. 평상시 복귀, 상담 결과, 공포 흔들림은 이 위치를 기준으로 해야 한다. `Vector2.zero`로 강제 초기화하지 않는다.

## 미구현 및 다음 우선순위

1. 장부, 천장 종, 부적, 귀신 정보창을 배경과 분리된 클릭 UI로 제작.
2. 귀신 클릭 도감: 관계, 알려진 고민, 금기 `???` 해금.
3. 침묵 금기 이벤트: 전체 입력 잠금, 무입력 감지, 빨강·검정 공포 효과.
4. 칠판형 상담판을 현재 임시 패널 대신 픽셀 UI 아트로 교체.
5. 귀신 초상·표정·공포 형태와 사운드 적용.
6. 7일 전체를 수동으로 완주하며 저장·수입·결산 밸런스 검증.
