# 구현 현황과 확장 로드맵

## 현재 구현된 프로토타입

`Assets/GhostCounselor`에 7일 상담 게임의 기본 흐름이 구현되어 있다.

- 5명의 귀신 콘텐츠와 첫 방문·재방문 대사.
- 하루 한 명 방문, 첫 방문 우선 보정.
- 질문 선택, 10초 자연어 답변, 5초 공포 표정 변화.
- 로컬 답변 의도 판정과 동일 의미의 선택지 대체 답변.
- 네 단계 상담 결과, 사례비, 특별 물건 환전, 관계 변화, 업적.
- JSON 저장·이어하기·7일 결산.
- 콘텐츠, 대표 답변 판정, 저장 데이터 직렬화 검증.

## 현재 구현의 경계

- 실제 외부 AI 서버는 아직 연결하지 않았다. 현재는 오프라인 로컬 판정기를 사용한다.
- 실제 AI를 붙일 때도 서버는 `공감`, `현실적 조언`, `회피`, `공격`, `문맥 이탈` 같은 승인된 의도 값만 반환해야 한다.
- 배경 픽셀 아트, 캐릭터 스프라이트, 종·장부·도감 UI의 완성 아트는 아직 제작 전이다.
- 침묵 금기 이벤트와 귀신 도감 UI는 기획만 확정된 상태다.

## 다음 제작 순서

1. 신당 고정 배경을 제작하고 안전 영역을 확정한다.
2. 칠판, 종, 장부, 상단 정보 UI의 픽셀 스프라이트를 제작한다.
3. 현재 코드 기반 UI를 새 아트 프리팹으로 교체한다.
4. 귀신 클릭 도감과 금기 해금 데이터를 추가한다.
5. 침묵 금기 이벤트의 입력 잠금·무입력 감지·공포 효과를 구현한다.
6. 다섯 귀신의 초상, 표정, 공포 형태, 효과음과 함께 7일 전체를 플레이 테스트한다.
7. 밸런스가 검증되면 30일, 경매, 조합, 상담소 확장으로 넓힌다.

## 검증 기준

- Unity 컴파일 오류가 없어야 한다.
- 저장 후 날짜, 돈, 귀신 관계, 물건, 업적이 복구돼야 한다.
- 5초 공포 변화와 10초 시간 초과가 정상 동작해야 한다.
- AI 연결 실패 또는 자유입력 불가 상태에서도 선택지로 끝까지 진행할 수 있어야 한다.
- 침묵 금기 이벤트에서는 모든 인터랙션이 명확히 금지되고, 무입력 성공이 가능해야 한다.
