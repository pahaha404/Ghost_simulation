# 신당 UI와 인터랙션 설계

## 레이어 원칙

1. 고정 배경: 신당 실내 픽셀 아트.
2. 공간 오브젝트: 귀신 캐릭터와 천장 종.
3. 상담 UI: 칠판, 대사, 질문, 자연어 입력.
4. 전경 도구 UI: 장부, 부적, 의뢰 물건.
5. 상단 정보 UI: 날짜, 보유금, 상태.
6. 전체 화면 효과: 붉은 점멸, 검은 침식, 결과 팝업.

## 칠판형 상담판

왼쪽 벽의 빈 틀 위에 별도 UI 스프라이트로 올린다. 평소에는 벽 장식처럼 보이지만 상담 때 앞으로 강조한다.

- 제목: 오늘의 고민 또는 귀신 이름.
- 본문: 귀신의 현재 고민.
- 예시 답변: 분필로 쓴 2~3개의 선택형 힌트.
- 자연어 답변: 핵심 상담에서만 켜지는 빈 분필칸 또는 종이 메모칸.
- 타이머: 모래시계 또는 작은 방울 모양 숫자.
- 5초 경과: 글씨 흔들림, 붉은 테두리, 분필 가루 효과.
- 시간 초과: 분필 글씨가 지워지거나 검은 손자국이 번짐.

## 천장 종

배경에는 고리와 들보만 그리고, 종 본체·끈·빛·흔들림은 독립 스프라이트로 만든다.

- 평상시: 약하게 흔들리는 종.
- 사용: 클릭 또는 드래그로 좌우 흔들림, 종소리, 픽셀 잔상.
- 효과: 일반 귀신의 경계를 잠시 낮추거나 위험 상태를 진정시킨다.
- 제한: 하루 또는 상담당 1회. 부적 충전 표시로 남은 사용량을 보여 준다.
- 주의: 침묵 금기 귀신 앞에서는 종을 울리는 행동이 즉시 실패 조건이 될 수 있다.

## 장부/노트

하단 탁자 위의 닫힌 노트 아이콘을 클릭하면 중앙 오버레이로 펼친다.

- 장부: 보유금, 일자별 수입, 월세·빚 목표.
- 손님: 만난 귀신, 관계, 해결 상태, 재방문 단서.
- 물건: 받은 귀신 물건과 환전 가치.
- 업적: 달성 조건과 달성 여부.
- 기록: 본 핵심 대사와 상담 결과.

핵심 10초 답변 또는 침묵 금기 이벤트 중에는 열 수 없다.

## 상단 정보

- 현재 일자와 남은 영업일.
- 보유금.
- 장부 열기 버튼.
- 필요 시 종 사용 횟수 또는 위험 상태 표시.
