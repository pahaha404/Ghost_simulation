# 프롤로그: 귀신 상담소

## 용도

게임 실행 직후, 신당 배경과 제목 화면보다 먼저 나오는 검은 화면의 흰색 본문이다.

- Unity 원고: `Assets/Resources/Stories/Prologue.txt`
- Unity 객체: `SampleScene > Prologue UI - Opening Story`
- 진행: `다음 >` 버튼을 누를 때마다 원고의 빈 줄을 제외한 한 줄이 중앙에 나타난다.
- 종료: 마지막 `귀신 상담소.` 뒤의 `시작하기` 버튼을 누르면 프롤로그 Canvas가 꺼지고 일반 제목 화면이 나타난다.

## 확정 원고

```text
나는 무당이다.

사람들 앞에서 북을 치고, 방울을 흔들고,
없는 조상도 있는 척 불러냈지만...

요즘 사람들은
귀신보다 카드값을 더 무서워하나보다.
도통 손님이 없다.

굿판은 줄었고,
신당 월세는 밀리고...

결국 나는 문을 닫기로 했다.

마지막 향에 불을 붙이던 날,
누군가 문을 두드렸다.

“여기… 상담도 합니까?”

문을 열었을 때,
거기엔 사람이 없었다.

귀신이었다.

“돈이라면 많아요. 제발 내 얘기 좀 들어주세요.”

그래서 그냥, 들어줬다.

살아서도 아무한테 못 했던 얘기.
죽어서도 끝나지 않은 얘기.

한 시간쯤 지나자
귀신은 금괴 두 짝을 두고 조용히 사라졌다.

그리고 다음 날부터,
신당 앞에 줄이 생기기 시작했다.

사람 줄은 아니었다.

“여긴 성불시키는 데가 아니라며?”
“말은 들어준다던데.”
“소개받고 왔습니다.”

그렇게 나는
망해 가던 신당의 간판을 바꿨다.

귀신 상담소.
```

## 연출 기준

- 배경은 순수한 검은색이다. 신당 배경을 사용하지 않는다.
- 본문은 흰색, 화면 중앙에 한 줄씩 표시한다. 새 줄은 짧게 페이드인한다.
- 마지막 `귀신 상담소.`는 같은 흰색을 유지하되 더 큰 글자로 제목처럼 남긴다.
- 프롤로그에서는 다른 버튼·HUD·귀신·배경 장식을 보이지 않는다.
