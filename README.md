# 《귀신 상담소》

따뜻한 괴담 코미디 분위기의 2D 귀신 상담 운영 시뮬레이션입니다.

플레이어는 폐업 위기의 신당을 물려받은 초보 무당이 되어, 7일 동안 찾아오는 귀신들의 고민을 듣고 월세와 빚을 갚아 나갑니다.

## 프로젝트 열기

Unity 프로젝트는 [`Ghost`](Ghost/) 폴더에 있습니다. Unity Hub에서 `Ghost` 폴더를 프로젝트로 열어 주세요.

## 현재 프로토타입

- 7일 동안 하루 한 명의 귀신 상담
- 선택형 질문과 10초 자연어 답변
- 상담 결과, 사례비, 관계, 업적, 저장/이어하기
- 귀신 초상, 타자기 답변 UI, 장부와 도감 UI
